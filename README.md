# 🚆 IRCTC-Inspired Travel Booking Website

A modern, responsive travel booking website inspired by IRCTC, built using **HTML, CSS, and JavaScript**. This project allows users to explore destinations, search for trains and buses, view travel details, book tickets, select seats, and track their journeys through an interactive interface.

## 🌐 Project Overview

The website provides separate experiences for train and bus bookings. Users can switch between travel modes, search for available options, explore popular destinations, and manage their demo bookings.

## ✨ Features

### 🚆 Train Booking
- Search trains by source and destination.
- Select journey dates.
- View train information and ticket fares.
- Book train tickets.

### 🚌 Bus Booking
- Search buses by source and destination.
- View bus names, routes, images, and prices.
- Explore individual bus details.
- Select seats and calculate ticket fares.
- Book bus tickets.

### 🌍 Explore Destinations
- Browse popular travel destinations.
- View destination images and descriptions.
- Explore tourist attractions.
- Check the best time to visit.
- Navigate to destination details and booking.

### 🎫 Booking Management
- Interactive booking form.
- Seat selection.
- Automatic fare calculation.
- Booking confirmation.
- View previously saved bookings.

### 📍 Journey Tracking
- Enter a booking or tracking ID.
- View simulated journey status.
- Check journey progress through a tracking timeline.

### 📱 Responsive Design
- Modern user interface.
- Responsive layout for desktop, tablet, and mobile.
- Interactive navigation and search sections.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/irctc-travel-booking-website.git
   ```

2. Open the project folder in VS Code.

3. Install the **Live Server** extension if you haven't already.

4. Right-click `index.html`.

5. Select **Open with Live Server**.

6. Explore the website in your browser.

## 🧪 How to Test

1. Open the homepage.
2. Switch between Train and Bus booking.
3. Search for buses or trains.
4. Click destination images to explore destination details.
5. Open bus details and select seats.
6. Complete the demo booking form.
7. Visit My Bookings to see saved bookings.
8. Use the tracking page to check simulated journey progress.

## ⚠️ Important Notes

- This is a frontend demonstration project, not an official IRCTC website.
- Bookings are stored in browser LocalStorage.
- No real tickets are issued.
- Payment processing is not integrated.
- Journey tracking uses simulated information, not live GPS data.
- Bus and train information is sample data.
- Internet access is required to load remote Unsplash images.
